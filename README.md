Ember Harvest — a neon arcade game. You are a firefly gathering the last golden embers of a dark garden: catch embers to grow your light and your combo, dodge the shadow wisps that hunt it, and survive level after level as the dark thickens. Three lights, power-ups, synthesized sound, and a full loop: title, play, pause, and a game-over screen with restart.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Move with the mouse or WASD / arrow keys. P pauses, M toggles sound, R restarts after game over.
